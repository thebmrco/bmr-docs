# <Icon name="layout-panel-left" size="1em" /> Anatomy of a Catalog Item

<PageIntro illustration="catalog" meta={['Reference', 'Fields set by BMR']}>

One item = a **3D model** + **fields** that say what it is, how big it is, where it goes and what it does.

</PageIntro>

This page lists the fields **every** item has. Extra data per category — ports, devices, absorption values — is in [Requirements by Category](category-requirements).

:::info Added by BMR, not by users
The **BMR team** fills in these fields. Customers see them in the catalog and place the item.
:::

---

## <Icon name="circle-check" size="1em" /> The shared backbone

| Field | What it is |
|---|---|
| **Name** | Internal key — lowercase, underscored |
| **Display Name** | The label shown in the catalog |
| **Brand** | Manufacturer |
| **SKU** | Manufacturer part / model number — **the way an exact product is identified**. Always captured when the item has one |
| **Category** | Decides which extra fields apply |
| **Material** | Primary materials, comma-separated (*plastic, glass*) |
| **Description** | Short summary |
| **Color** | Finish, or the available options |
| **Average Price** | Indicative *(optional)* |
| **Measurements** | Width × height × depth |
| **Link** | Manufacturer product page *(optional)* |
| **Thumbnail** | Catalog image — JPG, PNG or GIF |
| **GLB File** | 3D model for BMR Studio |
| **USDZ File** | AR model for iPhone and iPad |
| **Features** | Capability flags — see below |
| **Mounting Types** | Where the item can go — see below |
| **Equipment group** | Items in one group can **replace each other** in BMR Studio and **share colour palettes** *(optional)* |
| **Ports verified** | Port positions have been checked against the real device |
| **Tags** | Labels for grouping and search *(optional)* |

## <Icon name="scan" size="1em" /> Features

Simple yes/no flags. They tell BMR Studio what an item can do. Any combination is allowed.

**Device capabilities**

| Flag | Meaning |
|---|---|
| **Screen** | Has a display surface |
| **Touch** | The screen is touch-capable |
| **Camera** | Has a camera |
| **Microphone** | Has one or more microphones |
| **Speaker** | Has audio output |
| **Control Device** | A touch panel or room controller — gets control-panel screen images instead of display ones |

**Physical properties**

| Flag | Meaning |
|---|---|
| **Resizable** | Can be scaled to other sizes |
| **Is Mount** | A bracket, stand or mount that holds other equipment — see [mounting points](ports-and-devices#-mounting-points) |
| **Curtain** | A curtain — placed as a run of sections; its drop can be set in BMR Studio |
| **Reflectivity** | Has a reflective surface that matters for acoustics or optics |
| **Acoustic** | Acoustic treatment — carries absorption values |
| **Allows branding** | Its face can carry a printed picture, so it can be used for a **panel mural** |

## <Icon name="marker" size="1em" /> Mounting types

Where an item can physically go. BMR Studio and AR Design use them to place it.

| Mounting type | The item… |
|---|---|
| **Floor** | Stands on the floor |
| **Wall** | Mounts on a wall |
| **Table** | Sits on a table or desk |
| **Ceiling** | Mounts on the ceiling |
| **Rack** | Mounts in a rack |
| **Display Top** | Sits on top of a display, e.g. a camera |
| **Mount** | Attaches to a mount's mounting points, e.g. a display on a bracket |
| **VESA** | Has a VESA fitting (displays, video bars) |
| **Camera Screw** | Fixes to a ¼"-20 camera screw |

---

## <Icon name="rotate-3d" size="1em" /> The 3D model

| File | Used in |
|---|---|
| **GLB** | **BMR Studio** on the web |
| **USDZ** | **AR Design** on iPhone and iPad |

Both must meet the [3D Model Standards](3d-model-standards). Ports, devices (cameras, microphones, speakers, screens) and mounting points are placed on the model in the [3D Configurator](ports-and-devices).
