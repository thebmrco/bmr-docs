## <Icon name="search" size="1em" /> Discovery

Features for capturing the current state of a room.

| Feature | Platform | Internal | Beta | Release | Notes |
|---|---|---|---|---|---|
| [Scan](../lifecycle/discovery/room-scan) | iOS | ✅ β01 | ✅ β01 | ✅ 1.4 | LiDAR-based 3D room scan. iPhone 12 Pro+ / iPad Pro 2020+. Screen dimming disabled since β08. |
| [Marker](../lifecycle/discovery/markers) | iOS | ✅ β01 | ✅ β01 | ✅ 1.4 | Photo markers for outlets, displays, cables. Can be added independently of scan since β04. Guided "what to capture" checklist added 1.4. |
| Marker 360 | iOS | 🔧 In development | 🗓 Planned | 🗓 Planned | 360° photo capture for richer spatial context at marker locations. |
| [Compass](../lifecycle/discovery/room-scan#compass-orientation) | iOS · Web | ✅ β09 | ✅ β09 | ✅ 1.4 | Captures room orientation during scan. Displayed in BMR Studio to reference walls by cardinal direction and inform layout decisions. |
| Room detection & relocalization | iOS | ✅ 1.4 | ✅ 1.4 | ✅ 1.4 | Relocalizes against the original scan when adding a marker, AR design, or acoustic measurement. Pinpoints speaker and measurement positions. Redesigned in [2.2](../release-notes/2026-09-release-2.2): "% of room seen", direction hints and "Room recognised". |
| Improved object detection | iOS | 🔧 In development | 🗓 Planned | 🗓 Planned | Enhanced recognition accuracy and reduced manual corrections during room capture. |
| Room measurements | iOS · Web | ✅ β03 | ✅ β03 | ✅ 1.4 | Floor area, volume, and dimensions calculated from scan data and shown in the room overview. |
| [Acoustic measurement](../acoustics/acoustics-guide) | iOS | ✅ β01 | ✅ β01 | ✅ 1.4 | Sweep (recommended) and balloon/impulse methods. Returns RT60 + MOS score. Guided flow added β08. Spatial position recording added β09. Confirm Room step, measurement positions, ambient noise on impulse, and full offline flow added 1.4. |

## <Icon name="design" size="1em" /> Design

Features for planning what a room should become.

| Feature | Platform | Internal | Beta | Release | Notes |
|---|---|---|---|---|---|
| BMR Studio | Web | ✅ β09 | ✅ β09 | ✅ 1.4 | Single web-based 3D environment for room design. Multiple guided modes expose only relevant tools per workflow. |
| Design versioning | Web | ✅ 1.4 | ✅ 1.4 | ✅ 1.4 | Versions created automatically on save or mode change. Review, rename, activate, or delete from the Versions tab. Save as New Design for a separate design. |
| Presentation mode | Web | ✅ 2.3 | ✅ 2.3 | ✅ 2.3 | Full-screen, step-by-step presentation of a design (**Shift + F**). Standard views first, then your own saved views, managed from the Presentation tab in View mode. Read-only shares can present too. |
| Render modes | Web | ✅ 2.3 | ✅ 2.3 | ✅ 2.3 | Standard and High quality rendering, chosen from the toolbar in View mode. High quality adds bounce lighting and ambient occlusion. Finer settings in the Rendering panel. Viewer runs on WebGPU where supported. Photoreal (path-traced) rendering is 🔀 switched on per organisation. |
| Design comparison *(legacy)* | Web | ✅ β04 | ✅ β04 | ✅ 1.4 | Side-by-side comparison of designs in the previous design view. Covers acoustics, layout, and equipment differences. Not available in BMR Studio. |
| Design comparison in BMR Studio | Web | 🗓 Planned | 🗓 Planned | 🗓 Planned | Side-by-side view mode comparison within BMR Studio. Planned for a future release. |
| AR design | iOS | ✅ β01 | ✅ β01 | ✅ 1.4 | Real-time 3D equipment placement via LiDAR on iOS. Design can be continued in BMR Studio on web. |
| Cisco VRC | Web | ✅ Available | 🔀 Toggle | 🔀 Toggle | Video Room Calculator — Cisco's 2D room design tool, integrated as a second design path focused on Cisco devices. Web-only; BMR Mobile shows a web-only message for VRC designs. |
| Active design | Web | ✅ β09 | ✅ β09 | ✅ 1.4 | The design set with **Activate** — the authoritative record of the room as it currently exists. Used as the reference for maintenance, troubleshooting, and future design cycles. |
| [Acoustic optimisation proposal](../release-notes/2026-10-release-2.4) | Web | 🔀 Toggle | 🔀 Toggle | 🔀 Toggle | Simulates acoustic treatment from your catalog for a measured room and scores the result. **Create new acoustic design in BMR Studio** turns it into a design. |
| Room auralizations | Web | 🗓 Planned | 🗓 Planned | 🗓 Planned | Simulated room acoustics to validate design decisions before deployment. On the 3–6 month roadmap. |

| Mode | Internal | Beta | Release | Notes |

Auto-Route, Tidy Bundles and Draw Cable were removed in 2.4. **Beta** label since 2.3. |
| Acoustics | 🔀 Toggle | 🔀 Toggle | 🔀 Toggle | Guided acoustic design. Only acoustic-relevant tools shown. Opened from an [acoustic optimisation proposal](../release-notes/2026-10-release-2.4). |
:::
