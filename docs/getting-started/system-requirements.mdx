# <Icon name="laptop" size="1em" /> System Requirements

<PageIntro illustration="scan" meta={['BMR Mobile on iPhone or iPad', 'Web in any modern browser']}>

Use the **recommended** setup for the best result. The **minimum** is the oldest that still works.

</PageIntro>

---

## <Icon name="smartphone" size="1em" /> iPhone / iPad {#-iphone--ipad}

<a id="supported-models-with-lidar" />

| | Recommended | Minimum |
|---|---|---|
| **iPhone** | **iPhone 15 Pro** or newer | iPhone 12 Pro / Pro Max |
| **iPad** | **iPad Pro (M4, 2024)** or newer | iPad Pro 11" (2nd gen, 2020)<br />iPad Pro 12.9" (4th gen, 2020) |
| **Software** | **Latest iOS / iPadOS** (now 27) | iOS / iPadOS 26 |

Scanning needs a **LiDAR** sensor. iPhones without "Pro" in the name have none, so they can't scan rooms.

---

## <Icon name="laptop" size="1em" /> PC / Web {#-pc--web}

Any modern browser works. Recommended for the best 3D performance:

| | Recommended |
|---|---|
| **Browser** | Latest **Chrome**, **Edge**, **Safari** or **Firefox** |
| **Mac** | Apple Silicon (**M2 or newer**), **16 GB** RAM, macOS Ventura (13) or newer |
| **PC** | Intel i5 / AMD Ryzen 5 or better, **16 GB** RAM, a dedicated GPU |
| **Screen** | 1920×1080 or higher |
| **Internet** | 50 Mbps or faster |

The 3D viewer in BMR Studio uses **WebGPU** where the browser supports it, and falls back automatically where it doesn't. Only the **Photoreal** render mode <FeatureToggleTag /> needs WebGPU.
