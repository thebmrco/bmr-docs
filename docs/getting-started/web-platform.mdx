# <Icon name="laptop" size="1em" /> The web platform at a glance

<PageIntro illustration="admin-work" meta={['Web platform']}>

Home, the menu, the header. Where things are, so you stop hunting.

</PageIntro>

The web platform is where you manage, analyse and design. Open it at **app.bettermeetingrooms.com**. What you see depends on your role: you only get the organisations, locations and rooms you have access to.

---

## <Icon name="home" size="1em" /> Home {#home}

Home opens with **Welcome back** and your name. It is the same page as **Overview** in the menu.

| Part | What it does |
|---|---|
| **Organization** | Pick **All Organizations** or one. Search by name; the **Recent** ones come first. With one picked, **Open organization overview** takes you to it |
| **Tiles** | **Organizations**, **Locations**, **Rooms**, **Active Designs** and **Open Tasks**. **View** opens the list behind a number. Some tiles also show what changed, such as *+3 this month* |
| **Recently Updated Rooms** | The rooms that changed last. **Area** narrows it to **Room data**, **Scans**, **Acoustics** or **Designs** |
| **Open Tasks** | Your own open tasks. **More...** opens the full list, see [My Tasks](./my-tasks) |

The **Area** you pick and the number of rows are remembered.

## <Icon name="layout" size="1em" /> The menu {#menu}

The menu is on the left. The arrow at its edge folds it down to icons.

| Section | Entry | Opens |
|---|---|---|
| **Main** | **Overview** | [Home](#home) |
| | **My Organizations** | The organisations you belong to, see [Organisation](../structure/organisation) |
| | **My Locations** | Your locations, see [Location](../structure/location) |
| | **My Rooms** | Your rooms, see [Room](../structure/room) |
| | **My Tasks** | [Tasks assigned to you](./my-tasks) |
| | **Data Analysis** <FeatureToggleTag /> | [Coverage and acoustics across the organisation](../lifecycle/maintenance/data-analysis) |
| **Library** | **Scans** | Every room scan |
| | **Designs** | Every design. Open one in [BMR Studio](../lifecycle/design/bmr-studio) |
| | **Legacy Designs** | Older designs |
| | **Acoustics** | Every [acoustic measurement](../acoustics/acoustics-guide) |
| | **Equipment** | Every item your organisation can use, read only. For an **Admin**, see [Equipment page](../catalog/equipment-page) |
| | **Trash** <FeatureToggleTag /> | What was deleted, with a counter |

## <Icon name="user" size="1em" /> The header {#header}

Across the top, from left to right:

| Part | What it does |
|---|---|
| **Breadcrumbs** | Where you are. Click a step to go back up |
| **Search rooms...** | Finds a room |
| **Send Feedback** | Sends us a problem or an idea, see [Send feedback](./send-feedback) |
| **Bell** | Your notifications, see [Notifications](./notifications) |
| **Documentation** | Opens this site |
| **Your picture** | **Profile** and **Logout**, see [Profile](./profile) |
