# <Icon name="comments" size="1em" /> Send Feedback

<PageIntro illustration="help" meta={['BMR Mobile', 'Web platform']}>

A bug, an idea or a question? Tell the BMR team with **Send Feedback**, without leaving BMR.

</PageIntro>

---

## <Icon name="circle-check" size="1em" /> Where to find it

| Platform | Where |
|---|---|
| **Web** (`app.bettermeetingrooms.com`) | **Send Feedback** button in the **header**, on every page |
| **BMR Mobile** (iPhone / iPad) | **Settings** → **Send Feedback** |

## <Icon name="comments" size="1em" /> What you can send

Pick a **Type**, write a short **summary** and a **description**.

| Type | When to use it |
|---|---|
| **Bug** | Something doesn't work — a button does nothing, data looks wrong, a flow breaks. |
| **Feature Request** | Something is missing or could be better. The Web button starts here. |
| **Question** | "Can BMR do X?" or "How should I handle Y?" |
| **Other** | Anything else. |

| | Web | BMR Mobile |
|---|---|---|
| Type, summary, description | Yes | Yes |
| Attachments | Up to **5 files**, 10 MB each — or paste a screenshot | — |
| Organisation, location or room | Optional | — |
| App logs | — | The **last 24 hours** are attached automatically |

:::tip Hit an error on the Web?
Many error messages have a **Report this issue** button. It opens the form as a **Bug**, with the error details already filled in.
:::

## <Icon name="map-pin" size="1em" /> Scoping the report {#-scoping-the-report}

Web only. Below the description, optionally pick what the report is about — an **Organization**, a **Location** or a **Room**. For a bug, this lets the team open the same room you were looking at.
