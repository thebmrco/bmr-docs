## <Icon name="admin-settings" size="1em" /> The admin area {#-the-admin-area}

Open the organisation on the web. Groups along the top, tabs beneath. Only an **Admin** can change things here.

| Group | Tabs | What it is for |
|---|---|---|
| **Overview** | — | Counts, Data Completeness, Recent Activity and the location list |
| **Users** | — | Who has access, and with which role — see [Inviting Users](../getting-started/inviting-users) |
| **Directory** | Locations · Rooms | The [locations](./location) and [rooms](./room) in the organisation |
| **Preferences** | General · Acoustic · Catalog · Branding | Organisation-wide settings — [below](#-preferences) |
| **Integrations** | Webex Sync · Microsoft 365 | [Webex Control Hub Sync](../integrations/webex-control-hub-sync) and [Microsoft 365](../integrations/microsoft-365) |
| **Room Configurations** | Yours · BMR Defaults | Recommended equipment per room size — [below](#room-configurations) |

## <Icon name="sliders-horizontal" size="1em" /> Preferences {#-preferences}

### General {#general}

| Setting | What it does |
|---|---|
| **Organization ID** | The identifier to quote when you contact support |
| **Cat figures** · **Monster figures** | Offer cats or friendly monsters as figure styles for the chairs in BMR Studio |
| **Trash retention** <FeatureToggleTag /> | How long deleted rooms, scans, designs and acoustics can be restored |
| **Delete this organization** | Moves the organisation, its locations, rooms and everything in them to the trash |

:::danger Deleting an organisation
You type the organisation's name to confirm. The other Admins get an email. Restoring from the **Trash** is a <FeatureToggleTag /> feature. Without it, there is no way back in the app.
:::

### Acoustic {#acoustic}

Defaults for new measurements. Earlier ones don't change.

| Setting | What it does |
|---|---|
| **Default measurement mode** | **Advanced** or **Basic** — see [Acoustic Measurement](../acoustics/acoustics-guide) |
| **Target MOS** | The score the organisation aims for, from 1.0 to 5.0. Data analysis views flag rooms below it |
| **Default room usage type** | The DIN 18041 usage class pre-selected when a room is created |
| **Default acoustics catalog** | The catalog whose acoustic items acoustic measurement uses |

:::tip Which measurement mode is used?
The device setting in BMR Mobile wins (**Settings → Acoustic Settings**). Then this default. Then **Advanced**.
:::

### Catalog {#catalog}

The catalogs you can use, with their item counts. BETTERMEETINGROOMS catalogs are **view only**; your own can be managed here. See [Catalog & 3D Models](../catalog/).

|---|---|

## <Icon name="sliders-horizontal" size="1em" /> Room Configurations {#room-configurations}

Recommended equipment per room size, suggested when you design a room.

| Tab | What it holds |
|---|---|
| **Yours** | Your organisation's own configurations — **Add a room configuration** to make one |
| **BMR Defaults** | Configurations from BETTERMEETINGROOMS, used when none of yours fits |

Fully documented in **[Default Room Configuration](../lifecycle/design/default-room-configuration)**.
