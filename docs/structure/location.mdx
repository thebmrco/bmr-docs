# <Icon name="location" size="1em" /> Location

A **location** is a physical site — an office, a building, a campus. It sits between the [organisation](./organisation) and its [rooms](./room) in the [structure](./), and holds the rooms at that site along with the site's address and coordinates.

---

## <Icon name="laptop" size="1em" /> The Location page on the web

<img src={useBaseUrl('/img/structure/location-page-web.png')} alt="Location page on the web showing the map, location details, data completeness per room, and recent activity" style={{width: '100%', borderRadius: '10px', border: '1px solid #E5E5D5', margin: '1rem 0'}} />

| Section | What it shows |
|---|---|
| **Map** | The site pinned at its coordinates |
| **Location Details** | Room and user counts, the full address, the owning organisation |
| **Data Completeness** | How many of the location's rooms are scanned, have markers, have an acoustic measurement, and have a design — each row links to those rooms |
| **Recent Activity** | The latest changes across the location, with who made them |
| **Advanced** | Integration IDs and raw coordinates |

Use the **Rooms** tab to work through the rooms themselves, and **Edit Location** to change the address.

The app shows the site on a map with its address, then lists every room with its data counts — scans, markers, acoustic measurements and designs — so you can see at a glance what each room still needs. **Add Room** creates a room in this location.

## <Icon name="map-pin" size="1em" /> Set the address from where you are standing

The most reliable way to get a location's address right is to fill it in **while you are on site**. BMR Mobile can take the address straight from the phone's GPS.

1. Open the location and tap the **pencil** beside its name.
2. On **Edit Location**, tap **Update data to current location**.
3. Confirm the prompt — *"This will update the address fields using your current location. Location permission is required."*
4. The app reads your position and fills in **Street Address**, **City**, **Postal Code**, **State / Province**, **Latitude** and **Longitude**.
5. Check the fields, correct anything the lookup got wrong, and tap **Save**.

:::note What to expect
- **Location permission** is required the first time — allow it when iOS asks.
- The coordinates come from the device; the street address is looked up from those coordinates, so an unusual building or a large site can return a neighbouring address. Always check before saving.
- Every field stays editable, so you can use the GPS as a starting point and adjust by hand.
:::

Getting this right matters beyond the address itself: the coordinates place the site on the map on both the web and in the app.
