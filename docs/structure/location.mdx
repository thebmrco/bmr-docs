# <Icon name="location" size="1em" /> Location

<PageIntro illustration="organise" meta={['Web platform', 'BMR Mobile']}>

A physical site — an office, a building, a campus. It holds the rooms at that site, their floors, and the site's address.

</PageIntro>

**[Organisation](./organisation) → Location → [Room](./room)** · see [Structure](./).

## <Icon name="layout" size="1em" /> Floors {#floors}

A floor is simply a name the rooms carry — a number, *Ground*, *B1* or *Mezzanine*.

| Where | What you do |
|---|---|
| **Rooms** tab | Filter by floor with the chips above the list, or sort by the **Floor** column |
| **Edit Location → Floors** | Add a floor name, then pick the rooms to move onto it. Rename a floor in one go. |
| The room's **Where** pencil | Set the floor of a single room — see [Room](./room#-moving-a-room) |

A floor exists as long as rooms are on it.

## <Icon name="map-pin" size="1em" /> Set the address from where you are standing

Fill in the address **on site** — BMR Mobile takes it from the phone's GPS.

1. Open the location and tap the **pencil** beside its name.
2. Tap **Update data to current location**.
3. Confirm — *"This will update the address fields using your current location. Location permission is required."*
4. The app fills in **Street Address**, **City**, **Postal Code**, **State / Province**, **Latitude** and **Longitude**.
5. Check the fields, fix anything that's wrong, and tap **Save**.

The coordinates place the site on the map, on the web and in the app.
