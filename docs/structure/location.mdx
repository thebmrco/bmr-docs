# <Icon name="location" size="1em" /> Location

<PageIntro illustration="organise" meta={['Web platform', 'BMR Mobile']}>

A building or site. **It holds its rooms, their floors, and the address.** Managed by a **Location Manager** or an Admin.

</PageIntro>

<StructurePath current="location" />

## <Icon name="laptop" size="1em" /> The Location page on the web {#-the-location-page-on-the-web}

<Figure
  src="/img/structure/location-page-web.png"

  caption="The Overview tab of a location."

| Part | What it shows |
|---|---|
| **Map** | The site at its coordinates |
| **Location Details** | Rooms, users, address, organisation |
| **Data Completeness** | How many rooms have a scan, markers, acoustics and a design. Click a row to see those rooms |
| **Recent Activity** | Latest changes, and who made them |
| **Rooms** tab | Every room, with its floor. **Create a new Room** |
| **Edit Location** | Address, and the **Floors** tab |

---

## <Icon name="layout" size="1em" /> Floors {#floors}

A floor is a name the rooms carry: *3*, *Ground*, *B1*, *Mezzanine*. It exists while rooms are on it.

| To | Go to |
|---|---|
| Filter by floor | **Rooms** tab, the chips above the list |
| Add or rename a floor, move rooms onto it | **Edit Location → Floors** |
| Set one room's floor | The room's **Where** pencil, see [Room](./room#-moving-a-room) |

## <Icon name="map-pin" size="1em" /> Set the address from where you are standing {#-set-the-address-from-where-you-are-standing}

On site, BMR Mobile fills in the address from the phone's GPS.

1. **Pencil** beside the location's name.
2. **Update data to current location**, then confirm.
3. Check the address and coordinates it filled in. **Save**.
