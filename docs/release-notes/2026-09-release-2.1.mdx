# Release 2.1 2026 September

**BMR Mobile is now public.** Version 2.1 is the first release of BMR Mobile available to everyone directly from the **Apple App Store**. It is the **same app as [Release 2.0](/docs/release-notes/2026-08-release-2.0)** — the same redesign and the same features — now publicly available.

:::info BMR Mobile is now on the App Store
Find and install **BMR Mobile** directly from the Apple App Store — no download link required. This is the app to use going forward.

The previous version — now listed as **BMR Mobile Private** — is **no longer supported** and should be **deleted** from your device.
:::

- For the full feature set, see **[Release 2.0 (2026 August)](/docs/release-notes/2026-08-release-2.0)**: the Liquid Glass redesign, the role-aware home screen, the rebuilt AR Design flow (beta), cabling infrastructure in BMR Studio (beta), read-only design sharing, the background-noise-aware MOS score, and the choice of acoustic measurement flow.
