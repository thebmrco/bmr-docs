# Release 2.1 2026 September

**BMR Mobile is now public.** Version 2.1 is the first release of BMR Mobile available to everyone directly from the **Apple App Store**. It is the **same app as [Release 2.0](/docs/release-notes/2026-08-release-2.0)** — the same redesign and the same features — now publicly available.

Alongside the public app launch, the **Web Platform** receives its September update: a new acoustics analysis view, a restructured organization admin area with a Branding tab, a major quality pass on photorealistic rendering, and more direct control in the editor.

:::info BMR Mobile is now on the App Store
Find and install **BMR Mobile** directly from the Apple App Store — no download link required. This is the app to use going forward.

The previous version — now listed as **BMR Mobile Private** — is **no longer supported** and should be **deleted** from your device.
:::

## Web Platform (2026.09.0)

<details className="bmr-details">
<summary className="bmr-summary">
  <span style={{display:"inline-flex", alignItems:"center", gap:"10px"}}>
    <ChartColumn size={18} /> New acoustics analysis view
  </span>
</summary>

Acoustic results are now broken down as **MOS impact per parameter**, making it easy to see exactly what is dragging a room's score down — and what to fix first.

- Each acoustic parameter is shown with its **individual impact on the MOS score**, instead of a flat list of raw values.
- Individual measurements can now be **deleted from a measurement group** — no need to discard the whole group over one bad take.

:::info Web only for now
The new acoustics analysis view is available on the Web Platform. It is **coming to BMR Mobile soon**.
:::

</details>

The organization admin area has been restructured, and branding gets a dedicated home.

- The admin page now uses a clearer **two-level navigation**, so settings are easier to find as organizations grow.
- A new **Branding tab** is where you upload your **logo** — moved out of BMR Studio into the organization settings where it belongs.
- A placed logo can now be **resized in BMR Studio**, so it fits naturally into any design.

</details>

<details className="bmr-details">
<summary className="bmr-summary">
  <span style={{display:"inline-flex", alignItems:"center", gap:"10px"}}>
    <Aperture size={18} /> Better photorealistic rendering
  </span>

The photorealistic (path-traced) render mode in BMR Studio received a major quality and stability pass.

- **Correct lighting** throughout the traced scene.
- **Faster renders at high resolutions**, including 4K.
- **Cleaner denoising** — no more artifacts at the edges of the image.
- **Broader browser support** — photorealistic rendering now works reliably across more browsers and devices.
- Wall transparency and the openings toggle now work in photorealistic mode too.

</details>

A persistent **View menu** replaces the old visualizations dropdown in BMR Studio.

- Switching between view modes is always **one click away**.
- The menu stays available while you work, instead of hiding options behind a dropdown.
- Measurements have moved into the View menu as well, replacing the footer legend.

</details>

Several editor improvements give you more direct control over a design.

- **Resize any element on all three axes** directly from the context toolbar — width, depth, and height.
- **Curtain drop height** can now be set manually, instead of being derived from the ceiling. Curtains can also be resized from each end independently.
- **Doors now default to a glass door**, matching the most common choice in modern meeting rooms.

</details>
