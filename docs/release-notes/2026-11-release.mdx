# November 2026: web 2026.11.x, BMR Mobile 2.4

This release is about working in **BMR Studio**. It opens in **View mode**, you choose how a design starts, editing is faster, **cables** follow the room and **Room modes** show where a room booms. Every organisation gets a **catalog of its own**. In **BMR Mobile 2.4**, **Continue scan** replaces Retake.

The web update is 2026.11.x, live on 24 November 2026. The matching app release is [BMR Mobile 2.4](#bmr-mobile-24). The release before this one is [Release 2.4 of October 2026](2026-10-release-2.4).

Features marked <FeatureToggleTag /> are switched on per organisation.

---

- **Studio opens in View mode.** Pick an item and **Edit** and **Delete** appear above it. **Edit** opens the mode that edits it, with the item still selected. See [Editing](../lifecycle/design/bmr-studio#editing).
- **A new header and a camera toolbar.** The file control, the **2D**, **Split** and **3D** switch with undo and redo, and who else is in the design, **Help** and **Share**. See [Moving the camera](../lifecycle/design/bmr-studio#camera).
- **One Space Configuration panel** holds everything the room shows. The **Room** tab is gone.

- **Welcome to BMR Studio.** The first time you open a design from a scan, you choose how it starts: **Placeholder blocks**, **Generic equipment** or **Remove everything**, **or** one of the default room configurations. A configuration removes everything in the room first, then places itself. See [the welcome](../lifecycle/design/bmr-studio#the-welcome).
- **Automatic design from scans** is an organisation setting, off by default. An Admin switches it on in **Preferences › General**. A processed scan then builds the room's design and makes it the **Active design**. **Scan models** choose which catalog item a scanned chair, table or display becomes. See [Scan models](../structure/organisation#scan-models).
- **Guidelines is now Room Configuration.** A room configuration places itself against the best-fitting wall, or centred on the floor, and what doesn't fit is marked **Does not fit**.

- **Replace** shows the catalog with the items of the same type first. Hover a card to see the item in place before you swap. See [Replace](../lifecycle/design/bmr-studio#replace).
- **Repeat, Select all of type, Distribute and Align.** **Repeat** works for every item, **Select all of type** picks every item like the one you clicked, **Distribute** spaces items out between two walls you click, and **Align** lines them up. See [Repeat, Distribute and Align](../lifecycle/design/bmr-studio#arrange).
- **The BOM and Properties.** The BOM lists every item in the room, catalog or not, and follows every edit at once, without saving first. Properties reads as name and value, in every mode. See [BOM](../lifecycle/design/bmr-studio#bom) and [Properties](../lifecycle/design/bmr-studio#properties).

Cable mode is still **Beta**. Check a route before you build from it.

- **Cables follow the room.** Routing runs on a graph of the room's edges and corners, and it is the new default. Cables follow angled walls instead of zigzagging on the grid.
- **Shape a route.** Select a cable and slide a run by its green pill. **Route via** sets whether the cable meets on the floor or the ceiling, and **Reset route** goes back to the automatic one. A run you slide by hand is kept for this session only. See [Shaping a route](../lifecycle/design/bmr-studio#cable-route).

## BMR Mobile (2.4) {#bmr-mobile-24}

BMR Mobile 2.4 follows [BMR Mobile 2.3](2026-10-release-2.3#bmr-mobile-23).

<details className="bmr-details">
<summary className="bmr-summary">
  <span style={{display:"inline-flex", alignItems:"center", gap:"10px"}}>
    <Icon name="scan" size="1.1em" /> Scan
  </span>
</summary>

- **Continue scan replaces Retake.** When a scan ends, one bar offers **Continue scan** and a checkmark to save. **Continue scan** reopens the camera in the same room: your scan, markers and photos stay and everything new merges in. <FeatureToggleTag />
- **A live model while you scan,** and a clear reason when a scan stops by itself: the device lost its position, is too hot, ran low on memory or reached the size limit. <FeatureToggleTag />
- **One dialog says why a scan is missing:** **Scan Needed**, **Re-scan Needed**, **Scan Not Uploaded Yet** or **AR Map Unavailable**. It says what happens if you carry on, and offers to scan or re-scan right away, to try again, or to **Continue Anyway**.
- **Your organisation decides whether the mesh is captured.** Change it on the Web Platform and it applies to the next scan, with no app update. <FeatureToggleTag />
- **The scan and the AR world map upload first,** so you can start AR Design or open the room on the web while the rest keeps uploading.

</details>

- **The optimisation proposal comes from BMR's servers,** so the app and the Web Platform show the same one. <FeatureToggleTag />
- **Fixes:** a new user with no family name can sign in again, two uploads of an AR world map for one room no longer collide, and acoustic results no longer loop or crash.
